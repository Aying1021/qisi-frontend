# 启思 · 数学学习教练

面向教育类竞赛的本机网页项目。围绕初中一元二次方程，演示“错题 → 说思路 → 分层提示 → 自己讲解 → 变式练习 → 学情统计”。

## 启动

电脑需要 Node.js 22 或以上版本，当前电脑已具备。项目使用 Node.js 自带功能，无需安装依赖或数据库。

1. 双击项目中的 `启动项目.cmd`。
2. 在浏览器打开 <http://127.0.0.1:8080>。
3. 保持启动窗口开启，按 Ctrl+C 停止。

也可在项目目录运行 `npm start`。若端口被占用，先关闭之前的服务，或在 `.env` 中添加 `PORT=3001`，然后访问新端口。

## 已完成的功能

- JPG / PNG / WebP 错题照片上传，调用真实 OCR 模型识别题目与原解；识别结果可修改。
- 输入自己的思路，真实 AI 进行初步错因诊断及启发式追问。
- 三层提示：概念提醒、下一步操作、不同的类似例题。
- 保留交流上下文，支持继续追问和提交新尝试。
- 学生用自己的话讲解；真实 AI 评估后决定继续补充还是进入练习。
- 程序生成一元二次方程变式并校验两个根，支持整数、小数、分数和重根。
- 错题记录、学习恢复、本机持久化、教师错因分布和学习阶段统计。
- 导出 JSON 学习记录。
- 固定示例演示模式，不调用 AI；演示数据与真实统计区分。
- 电脑和手机宽度的响应式布局。

## 一次比赛演示怎么走

### 真实 AI 模式（需要联网和可用模型额度）

1. 保持“真实 AI”模式，点击“填入一道示例错题”，或上传图片并核对结果。
2. 点击“开始探索”。
3. 思路填写：“我找了两个乘积为 6 的数 1 和 6，但没有检查中间项。”
4. 阅读追问，试用三层提示，并尝试继续交流。
5. 讲解填写：“要找乘积是 6、和是 −5 的两个数，即 −2 与 −3。展开 (x−2)(x−3) 得到原式，由零乘积性质得到两个根。之前的分解一次项是 −7x，与原式不符。”
6. AI 认可讲解后，独立完成变式题；若要求补充步骤，按追问补充。
7. 切换“教师学情”，查看实际练习统计。

这段话是操作示例，AI 的实际回复可能变化。上台前请提前确认网络、密钥和免费额度。

### 示例演示模式（无需模型连接）

选择“示例演示”，使用固定错题体验上述流程。示例诊断和提示为预设内容，不会理解任意输入，也不会认可学生讲解的正确性；变式题仍由程序生成并真实校验。界面会明确标记演示模式。

## AI 是怎么接进来的

调用路径：浏览器 → 本机 Node.js 后端 → 阿里云百炼 → 后端 → 浏览器。

- 后端从 `.env` 读取 `DASHSCOPE_API_KEY`，浏览器只向自己的后端发请求。
- 图片识别默认用 `qwen-vl-ocr-2025-11-20`，教学对话默认用 `qwen3.7-plus`。
- 后端通过 HTTPS 发送图片或对话，教学回复要求使用 JSON 格式，校验后再显示。
- 学习阶段、提示次数、变式答案校验由程序管理。
- AI 不可用时显示实际错误，不会静默替换成假回复；可手动选择演示模式。

真实 AI 模式会消耗账号的模型额度，本程序不能保证免费或替代云平台限额。请在百炼控制台确认所用模型的免费额度、有效期及“免费额度用完即停”设置。

## 配置与数据

当前本机 `.env` 已配置密钥。换电脑时参考 `.env.example` 创建 `.env` 并填入对应地域密钥。

```text
DASHSCOPE_API_KEY=在本机填入密钥
AI_MODEL=qwen3.7-plus
OCR_MODEL=qwen-vl-ocr-2025-11-20
```

`.env`、运行数据和测试产物已加入 `.gitignore`。密钥只供后端使用，不应放到网页脚本或公开仓库。免费额度不由本程序管理，不会自动充值。

真实学习记录保存在 `data/sessions.json`，重启后仍在。OCR 原图不写入记录；识别文字及交流会保存。导出的 JSON 不包含密钥或变式题标准根。

本项目只有学习昵称，没有账号认证，同一部署实例的学习记录对所有访问者可见。服务默认监听 0.0.0.0:8080，既可本机运行，也可部署到云平台（如 JD DevCloud）提供公网 HTTPS 访问；部署时通过平台环境变量配置 `DASHSCOPE_API_KEY`，密钥不进入代码仓库。云平台容器重启后本机文件数据会重置，演示场景可接受。

## 验证

运行 `npm test`：验证变式生成、数值解析、AI 异常处理、完整演示流程、记录持久化、请求来源及私密文件隔离。

运行 `npm run check:ai`：真实模型连接测试，消耗少量额度。

`scripts/smoke-live.mjs`：独立数据集下测试真实诊断、提示和讲解评估。

`scripts/browser-qa.mjs`：在 Windows Edge 后台浏览器检查桌面/手机布局、演示操作与真实图片识别；测试截图与数据在 `.qa`，不进入正式学习统计。

本次已通过自动化测试、真实文字接口及一张清晰测试图片识别。手写模糊照片及复杂题型需要更多样本验证，上传后应人工核对识别结果。AI 诊断和讲解评估不是数学正确性的严格证明，单次变式答对也不等于长期掌握。

## 文件位置

- `server.mjs`：本机网页服务、接口、学习阶段、记录存储。
- `lib/ai.mjs`：模型调用、教学任务说明、错误处理。
- `lib/math.mjs`：变式题生成和根的校验。
- `public/`：页面、样式和交互。
- `test/`：自动化检查。

当前版本没有支付、家长独立账号、多学科题库、语音陪练或长期个性化推荐，适合基本功能展示。
